# Handoff — 17/10/2026, sessão 35

## Objetivo e instruções vigentes

Implementar a preparação segura das credenciais da Shopee Affiliate Open API por organização e indicar onde o Administrador deve cadastrá-las localmente. Implementação de busca/geração de links só pode começar depois de validar o contrato oficial com credenciais válidas. Não inventar capacidades, não usar scraping, não exibir mocks como reais, não enviar DMs, não alterar OAuth Meta/campanhas/histórico/chaves e não fazer commit/push. O usuário aprovou o plano de descoberta e configuração.

## O que foi implementado

- Migration aditiva `007_shopee_organization_credentials.sql`: tabela privada por `organization_id`, ciphertext Fernet, autor e datas; RLS habilitado; grants revogados para `PUBLIC`, `anon` e `authenticated`.
- `ShopeeCredentialStore` cifra o par App ID/App Secret com a `TOKEN_ENCRYPTION_KEY` existente, aplica autorização por organização e nunca fornece os valores às respostas públicas. Leitura interna de credencial revalida membership `admin/operator` no escopo da organização.
- Rotas `GET` e `PUT /api/v1/shopee/credentials?organization_id=...`. Configuração/estado só para Admin; PUT exige App ID e Secret juntos, com App Secret `SecretStr` e `writeOnly` no OpenAPI. GET devolve apenas estado/datas. Nenhuma chamada Shopee está implementada.
- Área no cockpit **Contas Instagram → Integração Shopee**, protegida por `data-admin-only` e também pelo backend. Após salvar, os campos são limpos. O Secret atual nunca pode ser recuperado pela tela.
- Sem variáveis `SHOPEE_*` em `.env.local`; credenciais não são de instalação global porque devem pertencer à organização e à afiliada designada.
- A migration 007 foi aplicada ao Supabase após confirmar conexão, estado anterior (001–006, alvo ausente) e usar o runner de migrations do projeto. Nenhuma credencial foi gravada.

## Onde o usuário deve preencher

Iniciar a API com o comando do README:

```bash
.venv/bin/python -m uvicorn apps.api.main:app --host 127.0.0.1 --port 8000 --no-access-log
```

No mesmo computador, entrar em `http://127.0.0.1:8000/m0/connect#connections` como Administrador e acessar **Contas Instagram → Integração Shopee**. Inserir App ID e App Secret do Explorer oficial e salvar. Não enviar pelo chat nem colocar em `.env.local`. A API foi iniciada na sessão e `/health/live` respondeu 200 durante a validação, mas a sessão Uvicorn foi encerrada ao final; portanto inicie novamente antes de preencher. Túnel Cloudflare não foi iniciado nem necessário para o formulário loopback.
